*Constraint audit verification from reports/benchmark_audit.md: In strict mode, the scheduler verifies facility classification and attendee-level security credentials, rejecting unknown IDs, missing/non-finite clearances, and clearance deficits (guaranteeing 0 attendee violations). In unconstrained mode, an average of 59.6 requests per instance had clearance deficits (61 on Seed 42). Enforcing strict clearance reduces average scheduled placements from 112.8 to 70.2 (a delta of 42.6 placements). This 42.6 placement difference is a cascading room/slot contention effect across the schedule, distinct from the measured count of 59.6 clearance deficits.

Scheduling Algorithm

Priority Scoring
Each meeting request scores: base priority (1–5) × clearance weight × urgency flag. High-priority meetings are scheduled first and get first pick of available rooms.
Conflict Detection
Before assigning a room+timeslot, the scheduler checks: (1) room not double-booked, (2) required attendees have no overlapping commitments, (3) clearance level satisfied.
Greedy Assignment
Sorted priority queue. For each meeting, finds the earliest available room that satisfies all constraints. Unschedulable meetings are flagged and queued for rescheduling.
Utilization Optimization
After initial pass, a secondary sweep fills gaps with lower-priority meetings, maximizing room utilization without violating any constraints.
